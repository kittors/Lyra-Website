## Three kinds of thing

| Kind | What it is | After installing |
| --- | --- | --- |
| Plugin | A bundle of skills | Available in new chats right away |
| MCP server | An external program that gives the agent tools | Off until you switch it on |
| Skill collection | A set of `SKILL.md` files | Installed as one bundle you can switch on and off, like a plugin <Badge text="Next release" variant="note" size="small" /> |

## Installing

<Steps>

1. Open **Plugins** in the sidebar and search. You can also browse by category <Badge text="Next release" variant="note" size="small" />
2. Open a card for the details: what it does, and which skills or servers it brings.

   <Image src={detailLight} alt="The detail page for the Waza skill collection: its name, summary and Install button, with its README below" sizes="(min-width: 50rem) 48rem, 100vw" class="dark:sl-hidden" />
   <Image src={detailDark} alt="The detail page for the Waza skill collection: its name, summary and Install button, with its README below" sizes="(min-width: 50rem) 48rem, 100vw" class="light:sl-hidden" />

3. Click **Install**. MCP servers arrive switched off; turn them on under Settings → Plugins → MCP.
4. If an MCP server needs a key, fill it in on the detail page or under Settings → Plugins → MCP before switching it on <Badge text="Next release" variant="note" size="small" />

</Steps>

<Aside type="caution">
The market doesn't review code. An MCP server runs on your machine with your permissions, so check its launch command and repository before switching it on.
</Aside>

## Managing and updating

- **Settings → Plugins** has five tabs — Plugins, MCP, Skills, Rules and Extensions — where you switch things on and off and uninstall them. A button at the top right of the market takes you straight there.
- **Auto-update** <Badge text="Next release" variant="note" size="small" />: installed items keep up with new versions by default, checked about every 30 minutes. Turn off **Auto-update** in the market's `⋯` menu to be told about updates instead; the sidebar then shows how many are waiting.
- **Keys** <Badge text="Next release" variant="note" size="small" />: keys you enter for MCP servers are encrypted on this machine. They never go into `settings.json` and are never synced to your phone.

## Sources

The default source is the official [Lyra Plugin Market](https://market.07230805.xyz). To add another marketplace, enter its address under **Sources…** in the market's `⋯` menu; it must start with `https://` <Badge text="Next release" variant="note" size="small" />

To list something of your own, see [Publish to the market](/en/docs/extend/publish/).
