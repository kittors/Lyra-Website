Lyra doesn't ship with a model, so the first thing to do is add one. Until you do, messages can't be sent.

<Steps>

1. **Add a model provider**

   Open settings with the gear at the bottom of the icon rail on the far left (in a narrow window, where the sidebar becomes a drawer, it's at the bottom of the drawer), go to **Models** → **Add a provider**, and fill in three fields:

   | Field | What goes there |
   | --- | --- |
   | Base URL | The provider's (or relay's) API address |
   | API format | **Responses**, **Anthropic Messages** or **Chat Completions** |
   | API Key | The key your provider gave you |

   Pick the format your provider documents: Responses for OpenAI, Messages for Anthropic, and usually Chat Completions for other OpenAI-compatible services.

   Then click **Test** next to the API key; the result and the latency show on the button itself.

   Next, click **Fetch models** to read the model list from the endpoint and import the ones you want, or **Add a model** to enter a model ID by hand. Once a test passes, pick your usual model and choose **Make this the default**.

   <Image src={modelsDark} alt="Settings → Models: the provider list on the left; on the right, the selected provider's Connection card (Base URL, API format, API key) and its Models card" sizes="(min-width: 50rem) 48rem, 100vw" class="light:sl-hidden" />

2. **Start your first chat**

   Click **New chat** at the top of the sidebar. The welcome screen puts the composer in the middle, under “What would you like to build in …?”, with a row of suggestions below it — click one to put it in the composer. Describe what you want done; `Enter` sends, `Shift+Enter` adds a new line.

3. **Open a project**

   Click the project button just above the composer → **New project**, name it and add the folder your code lives in (once you have a project, there's also a `+` next to **Projects** in the sidebar). Conversations in that project run in its main folder.

   Prefer not to tie a chat to a project? Choose **Work without a project**.

4. **Choose how much to approve**

   Switch modes from the bottom left of the composer:

   - **Ask for approval**: asks before every file write, command and network call
   - **Auto approve** (default): read-only commands run on their own; everything else still asks
   - **Full access**: everything runs without asking

</Steps>

## Everyday moves

| To | Do this |
| --- | --- |
| Run a command or skill | Type `/` |
| Reference a file, folder, skill, agent or past chat | Type `@` |
| Bring back something you sent earlier | Press `↑` in an empty composer |
| Compact the context | Type `/compact` |
| Start a new chat | Type `/clear` |
| Show or hide the sidebar | `⌘B` |
| Move between conversations and pages you've visited | `⌘[` and `⌘]` (on Windows and Linux, `Alt+←` and `Alt+→`), or the arrows at the left of the toolbar |
