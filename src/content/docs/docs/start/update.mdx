Lyra 会自己检查新版本。安装包下载完先核对校验值，对得上才安装。

## 更新步骤

<Steps>

1. 有新版本时，侧栏左下角设置那一行的末尾会出现一个小圆点。点它，或者到「设置 → 关于」点「检查更新」。
2. 看一眼「这个版本改了什么」，点「下载安装」。下载可以暂停、继续，关掉对话框也会在后台接着下。
3. 下载完：
   - **macOS、Linux**：点「立即重启」，原地换成新版本。
   - **Windows**：安装程序会自动打开，按提示装完再启动 Lyra。

</Steps>

<Aside>
重启会中断正在进行的对话，挑手头没活的时候点。
</Aside>

## 多久检查一次

每次启动检查一次，之后默认每 6 小时一次。可以在「设置 → 关于」里改成 1 到 24 小时。

## 各平台怎么替换

| 你装的是 | 更新时 |
| --- | --- |
| macOS | 下载 `.zip`，解压后原地替换 Lyra.app |
| Windows | 下载对应架构的安装程序并打开 |
| Linux AppImage | 替换原来的 AppImage 文件，然后重启 |
| Linux deb | 弹出系统的密码框，用 `apt-get` 安装新包 |
| 其他方式（如 rpm 转装） | 不支持应用内更新，会带你去发布页 |

<Aside type="caution">
AppImage 放在不可写的目录里（比如 `/opt`）就没法原地替换，挪到自己的目录下再更新。
</Aside>

## 校验机制

- 每个版本都附带 `SHA256SUMS`，列着所有文件的 SHA-256。
- 安装包下载完、安装之前逐一核对。对不上就删掉下载的文件，不安装。
- 版本没有附校验文件，或者取不到校验文件，同样不安装。宁可不更新。

## Windows 安全中心拦截

未签名的大安装包容易被 Microsoft Defender 当成可疑文件，表现是下到快结束时报「下载失败」。

<Steps>

1. 打开「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」，找到和 Lyra 有关的条目，选「允许」。
2. 在「病毒和威胁防护 → 管理设置 → 排除项」里，把更新目录加进去：`%APPDATA%\@lyra\desktop\updates`
3. 回到 Lyra 重试。已经下好的部分还在，会接着下。

</Steps>

## 连不上 GitHub

应用内更新从 GitHub 下载。网络到不了 GitHub 时，去[下载页](/download/)手动下载新版本，直接覆盖安装。会话和设置都在 `~/.lyra` 里，重装不会丢。
