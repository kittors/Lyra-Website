Lyra 是一个独立的通用 AI 智能体。接上你自己的模型，它就能在你的电脑上读代码、改文件、跑命令；出门在外，拿手机也能接着聊。

<Image src={heroDark} alt="Lyra 主窗口：左边是项目和会话，中间是对话，右边是 Git 面板" sizes="(min-width: 50rem) 48rem, 100vw" class="light:sl-hidden" />

## 它是什么

- **自己实现的 agent**：内核、工具、技能、MCP 都从零写起，不是 Claude Code 或 Codex 的外壳。
- **模型由你来配**：接任意多个供应商，每个供应商下挂任意多个模型。
- **桌面加手机**：桌面端支持 macOS、Windows、Linux；手机端（Android、iOS）连到你电脑上的 Lyra，两边是同一份会话。
- **开源免费**：MIT 许可，代码在 [GitHub](https://github.com/kittors/Lyra)。
