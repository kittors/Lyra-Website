## macOS

### 提示「无法验证开发者」

到「系统设置 → 隐私与安全性」，找到 Lyra 点「仍要打开」。或者在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Lyra.app
```

### 提示「已损坏，无法打开」

那是 0.6.0 及更早的旧包，只能删掉，换新版本。

### 升级后截图变黑或失败

截图用的是系统的「屏幕录制」权限。升级之后 macOS 有时认不出这还是同一个应用：列表里明明还授权着，截出来却是黑的，或者直接报错。清掉 Lyra 的授权记录，让它重新问一次：

```bash
tccutil reset ScreenCapture dev.lyra.app
```

然后**完全退出** Lyra（`⌘Q`，关窗口不算）再打开，下次截图会重新弹出授权。还不行的话，到「系统设置 → 隐私与安全性 → 屏幕录制」把 Lyra 的开关关掉再打开，必要时用列表下方的减号删掉这一条。

<Aside type="caution">
`dev.lyra.app` 不能省。不带它的 `tccutil reset ScreenCapture` 会清掉**所有**应用的屏幕录制授权，会议软件、录屏工具都得重新授权一遍。
</Aside>

## Windows

### SmartScreen 拦截

弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。

### 装完提示缺少快捷方式、找不到 Lyra.exe

`Lyra.exe` 多半被 Microsoft Defender 当成可疑文件隔离了。到「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」找到对应条目，选「允许」，再重新运行一次安装包。

### 安装目录里有好几个 exe

| 文件 | 大小 | 是什么 |
| --- | --- | --- |
| `Lyra.exe` | 两百多 MB | 主程序，用它启动 |
| `Lyra-<版本>-<架构>.exe` | 一百多 MB | 安装包本身，通常是安装时把目录选成了下载文件夹 |
| `Uninstall Lyra.exe` | 几百 KB | 卸载程序 |

## Linux

- **AppImage 双击没反应**：先 `chmod +x`，再从终端运行，看看报错。它需要 FUSE 3，Ubuntu 22.04 及以后默认就有。
- **deb 装不上**：需要 glibc 2.34 及以上，Ubuntu 20.04、Debian 11 太旧。升级系统，或者改用 AppImage。

## 更新失败

| 现象 | 处理 |
| --- | --- |
| Windows 上下到快结束时失败 | Defender 拦了安装包。在保护历史记录里允许 Lyra，把 `%APPDATA%\@lyra\desktop\updates` 加进排除项，再重试，已下的部分会保留 |
| 提示校验和不一致 | 下载的文件不对，已自动删除。重新下载；反复出现就换个网络 |
| 提示没有校验文件 | 这个版本无法验证，Lyra 不会安装。到[下载页](/download/)手动下载 |
| 提示连不上 GitHub | 应用内更新走 GitHub。到[下载页](/download/)手动下载，覆盖安装即可 |
| AppImage 替换失败 | 它放在不可写的目录（比如 `/opt`），挪到自己的目录下再更新 |

更多说明见[更新](/docs/start/update/)。

## 发不出消息

| 提示 | 处理 |
| --- | --- |
| 还没有可用模型 | 到「设置 → 模型设置」添加供应商 |
| 凭证被拒绝 | 检查这个供应商的 API Key 是否填对、是否过期 |
| 请求太频繁，被限流了 | 等一会儿再试，或换一个供应商 |
| 模型服务暂时不可用 | 对方服务端出错，Lyra 会自动重试 |

网络不稳时，可以在「设置 → 常规 → 请求重试」里调高重试次数。

## 手机连不上

- 电脑上「设置 → 移动端同步」里的服务在运行吗？
- 局域网直连要求手机和电脑在同一个网络。
- 提示令牌不对：在电脑上重新复制配对信息，或重新扫码。
- 不在同一个网络：改用公网地址或中转，见[手机端与同步](/docs/features/mobile/)。

## MCP 服务起不来

- **缺少密钥** <Badge text="下一版本" variant="note" size="small" />：在卡片上把缺的值填上，再打开开关。
- **连接失败**：卡片上会显示报错。用 `npx`、`uvx` 启动的服务第一次要下载，会慢一些。

## 还是没解决

到 [GitHub Issues](https://github.com/kittors/Lyra/issues) 反馈，附上系统、Lyra 版本和报错信息。
