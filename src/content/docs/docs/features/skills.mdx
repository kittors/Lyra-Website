技能是一个带 `SKILL.md` 的目录，教模型把某一类事按固定的做法做好。系统提示里只放它的名字和一句描述，模型决定要用时才去读正文，所以装几十个也不怎么占上下文。

## 从哪来

- **插件市场**：技能集，或插件里带的技能。
- **自己写**：见[写技能和插件](/docs/extend/plugins-and-skills/)。
- **项目里已有的**：`.claude/skills/`、`.agents/skills/` 里的技能直接能用，不用改格式。
- **候选技能**：打开「设置 → 个性化 → 自动沉淀项目记忆」后，Lyra 会从最近的会话里总结出可复用的流程，列在「设置 → 插件 → 技能」里等你确认，启用了才生效。

## 怎么用

- **让模型自己挑**：描述写清楚了，模型会在合适的时候调用。
- **手动调用**：在输入框输入 `/技能名`。
- **引用**：从 `@` 菜单的「插件与技能」里选一个，放进这条消息。

## 管理

在「设置 → 插件 → 技能」里开关、打开或删除。同名时越具体的越优先：

| 优先级 | 位置 |
| --- | --- |
| 1 | 项目里的 `.lyra/skills/` |
| 2 | 用户目录 `~/.lyra/skills/` |
| 3 | 插件带的 |
| 4 | 内置的 |

想改掉插件里某个技能的做法，在项目里放一个同名的技能目录就能盖过它。

<Aside type="tip">
描述太短（不到 40 个字符）会被标出来。模型只看描述决定用不用，写不清楚它就不会选。
</Aside>
