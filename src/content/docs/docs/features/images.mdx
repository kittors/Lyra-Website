## 加一个生图模型

<Steps>

1. 「设置 → 模型设置」→ 选供应商 →「添加模型」，填模型 ID，比如 `gpt-image-1`、`gemini-3.1-flash-image`、`dall-e-3`、`imagen-4.0-generate-001`、`flux-1.1-pro`、`doubao-seedream-4-0`。
2. 名字看得出会画图的，模型编辑里的「用途」会自动选成「生图」；自己起的名字（比如 `house-artist`）手动选。生图模型不会出现在对话模型的列表里。
3. 点这一行的测试按钮。它会真画一张小图，这一次会计费。

</Steps>

<Aside type="tip">
很多中转的 `/v1/models` 只列聊天模型，「拉取模型」里看不到生图模型。在它的搜索框里直接敲模型名、回车，就能把没列出的加进来。
</Aside>

## 用哪一个

只有一个就用它。有好几个时，在「设置 → 智能体 → 会话 → 生图模型」里选默认的，或者在供应商的模型列表里点「设为默认生图模型」；都没选就用第一个。

某个对话想换一个，有两种办法，换了都只对这个对话生效：

- **输入框上的魔法棒**：配了两个以上生图模型，或者两个以上视频模型时，模型按钮旁边会多一根魔法棒，悬停能看到现在用的是哪个。菜单里分「生图模型」「视频模型」两段，每段最上面是「跟随默认」。这个对话选了自己的，魔法棒就变成强调色；选的和默认不一样时，菜单里多一行「设为默认生图模型」。还没开对话时在这里选，改的是默认。
- **点名**：在消息里 @ 一个模型（`@` 菜单里有「生图与视频模型」一组），或者直接说「用 gpt-image-1 画」。这个对话后面的图都用它。一句话里点名两个、想比一比的，对话原来的模型不变。

## 画的时候

- 图的位置先按最终的比例占好，是一片缓缓流动的点阵。上方写着画到哪一步（「勾勒初稿」「铺陈画面」），右下角是百分比。
- 生图接口不报进度，百分比是按这个模型平常要画多久估出来的，图没到就停在 96%。图落下来时，下面的内容不会动。
- 一次要几张，就并排画几张，最多四张；其中一张失败，其余照样给你。
- 说「16:9 横图」「竖版手机壁纸」「正方形头像」，模型会选比例；想更清晰就说「高清」或「4K」。

## 改图

- 把图贴进输入框，再说要改什么。也可以直接指对话里已有的图：最新的一张是 `#1`，再往前是 `#2`。
- 鼠标停在画出来的图上，会出现「编辑」「再生成」和「下载」。「编辑」在标注工具里打开它：圈出要改的地方，按「完成」，带标注的副本就放进这个对话的输入框，光标停在它后面。说一句要怎么改、发出去，生图模型照着标注重画。你自己发过的图也能这样标。
- 「下载」存的是原文件，保存框里给的名字是 `lyra-image-2026-10-11-21-58-03.png` 这样带日期时间的。

## 换个模型再画

「再生成」有两样：

- **换个模型重画**：选另一个生图模型，提示词和参考图都不变。菜单里标着画这张的是哪个。
- **做成视频**：选一个视频模型，这张图附上去，从它做起。见[做视频](/docs/features/video/)。

只有一个生图模型、又没配视频模型时，没有这个按钮。选好之后，Lyra 在这个对话里替你发一句「用 @模型 重画这张图……」，新图和原来的那张一样落在对话里。输入框里有还没发出去的字时，这句话接在后面，等你自己发。

## 画失败时

卡片上会写明原因：

| 卡片上写着 | 怎么办 |
| --- | --- |
| gpt-image-1 的额度用完了 · 约 1h 53m 后恢复 | 等它恢复，或者换一个生图模型。这种失败不会自动重试 |
| 这个密钥不能使用 gpt-image-1 | 中转按分组限制了这把密钥（403 `model_not_allowed`）。到中转后台给密钥开放这个模型，或者把供应商地址换成包含它的分组，比如 `https://你的中转/group1` |
| 这次请求被内容安全策略拒绝了 | 同样的请求再发也会被拒。换个说法，或者去掉它不允许的内容 |
| 连接不稳，正在重试 | 网络抖动时最多再试两次，还不行就报出来，不会一直转圈 |

## 要知道的

- 所有对话里画过的图都收在左侧图标栏的「创作」里，能看到每张图是怎么一步步改出来的，见[创作](/docs/features/studio/)。
- 每画一张都是一次计费的调用，费用由生图模型的供应商收。「设置 → 使用统计」目前不算画图的花费。
- Lyra 先走 OpenAI 的 Images 接口（`/v1/images/generations`、`/v1/images/edits`），走不通再改用 Chat Completions、从回复里取图（OpenRouter 的格式），并记住每个供应商走通的是哪一条。
- 画出来的图存在 `~/.lyra/session-media/`，重开会话还在。
- 手机上看不到对话里画出来的图。
- 子智能体画的图留在它自己的面板里，不进主对话。
