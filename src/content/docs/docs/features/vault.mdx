对话里要用到密码、SSH 密钥或令牌时，值交给 Lyra，不交给模型。模型拿到的是一个名字，比如 `nas-root`，用的时候也只写这个名字。

## 对话里的凭据卡片

模型要一个凭据时（它调用 `request_credential`），输入框上方会出来一张标着「提供凭据」的卡片，标题是模型起的，比如「NAS 的 root 密码」。

<Image src={cardDark} alt="对话里的凭据卡片：模型要登上 staging 服务器，向你要 deploy 账号的密码。卡片标题是模型起的，下面引着它说的用途，再下面一行是 Lyra 写的「密码 · 只能用于 ssh://deploy@staging.atlas-api.dev」，然后是密码框，左边「拒绝」，右边「存进保险箱」和「提交」" sizes="(min-width: 50rem) 48rem, 100vw" class="light:sl-hidden" />

- 最上面引着模型说的用途。这句话是模型写的，不一定准。
- 下面一行是 Lyra 写的：哪一类（密码、账号密码、令牌、SSH 密钥），只能用于哪里，比如「只能用于 ssh://root@nas」。真正执行的是这一行。
- 填好按「提交」。勾上「存进保险箱」就存下来，以后的对话也能用；不勾，只在这个对话里有效。
- 保险箱里已经有同名同类的一份时，卡片上写着「保险箱里有一份」，按「使用保存的」就行，也可以「重新输入」。
- 不想给就按「拒绝」。模型会被告知：不要让你把它贴进对话。

SSH 密钥要粘贴私钥全文（以 `-----BEGIN` 开头），设了口令的把口令一起填上。填错了卡片会直接说：这是公钥、私钥口令不对，或者这不是一把私钥。

之后批准一条要用凭据的命令时，批准卡片上会列出「会用到的凭据」。

## 值去了哪里

- ssh、scp、sudo 和 git 来问密码时，由 Lyra 回答。
- SSH 密钥通过 Lyra 自己的 agent 借给 ssh、scp、rsync 和 git，命令里不用写 `-i`。
- 令牌放在环境变量里，交给要用它的那条命令。
- 在内置浏览器里填，先核对这一页是不是「只能用于」写的那个网站，不是就不填。
- 值要是从别处绕回来——命令把它打印了出来、模型读到的文件里写着它——模型看到的是 `[credential:nas-root]`。

## 保险箱

左侧图标栏「创作」下面那一格。卡片上存下的凭据都在这里，也可以自己加。

<Image src={vaultLight} alt="保险箱：四类凭据各一项——SSH 密钥、令牌、账号密码、密码。每一行是名称和类别，下面写着账号和只能用于哪里，没限定的写「不限地址」" sizes="(min-width: 50rem) 48rem, 100vw" class="dark:sl-hidden" />
<Image src={vaultDark} alt="保险箱：四类凭据各一项——SSH 密钥、令牌、账号密码、密码。每一行是名称和类别，下面写着账号和只能用于哪里，没限定的写「不限地址」" sizes="(min-width: 50rem) 48rem, 100vw" class="light:sl-hidden" />

<Steps>

1. 点「添加」，选密码、账号密码、令牌或 SSH 密钥。
2. 填「名称」，比如「NAS 管理员」。下面的引用名按名称自动起，可以改，只能用小写字母、数字和连字符；存下以后就不能再改了。
3. 填值。
4. 「只能用于」写 `ssh://用户@主机` 或 `https://网址`，留空表示不限。
5. 「交给对话前」选什么时候问你：「每个对话问一次」（默认）、「每次使用都问」，或者「不问，直接用」。

</Steps>

存进去的值不会再显示出来。点一行能改名称、「只能用于」和「交给对话前」；要换值就按「重新填写」，这一类的每一项都要重新填。

行上的按钮：

| 按钮 | 做什么 |
| --- | --- |
| 复制引用 | 复制 `[credential:名字]`。贴进消息里，这个对话就能直接用它，不再弹卡片（设成「每次使用都问」的照样会问） |
| 复制密码、复制令牌 | 把值放进剪贴板，30 秒后清掉。这期间你又复制了别的，就不动它 |
| 复制公钥 | SSH 密钥复制的是公钥那一行，不会清掉 |
| 删除 | 正在用它的对话也立刻用不了，不能撤销 |

改了「只能用于」或者删掉一项，已经在用它的对话马上跟着变，不用等到新对话。

## 问它密码是多少

问「NAS 的密码是多少」，模型还是看不到值，但它能用 `list_credentials` 查到保险箱里有哪些、叫什么，在回复里点名。那个名字画成一枚小胶囊，点一下就把值复制到剪贴板，30 秒后清掉。你自己贴进消息的引用，也画成同样的胶囊。

保险箱里没有这个名字的，胶囊点不了。

## 把密码贴进了消息

保险箱里存着的值，或者这个对话里卡片上填过的值，要是被你直接贴进消息，在消息保存和发送之前就会换成它的引用：模型和会话记录里只有 `[credential:名字]`。

## 手机上

凭据只能在电脑上填。手机上的卡片只能拒绝；回复里的胶囊要在电脑上点，才能复制。

## 要知道的

- 值加密存在 `~/.lyra/credentials.json`，解密的钥匙是同目录下的 `vault.key`，见[数据与隐私](/docs/help/data-and-privacy/)。
- 命令读不到这两个文件：在沙箱里直接被拒绝；完全访问模式下，读它们也会先问你，批准只算这一次。

<Aside type="tip">
别把密码打进消息里再让模型去用——直接说要做什么，它需要时会弹卡片。已经存进保险箱的，复制引用贴过去就行。
</Aside>
