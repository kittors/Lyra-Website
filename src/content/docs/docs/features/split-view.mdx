## 打开分屏

- **菜单**：在侧栏右键一个会话 →「打开方式」→「分屏」。它会作为新的一列加进来；宽度不够时切开一个够大的屏，还放不下就改开一个新窗口。
- **拖动**：把侧栏里的会话拖到某一屏上，靠近哪条边就分到哪一边。

已经有 4 屏时再拖进来，会替换指针下的那一屏。某一屏太窄、再分就看不清时，会提示「这一屏放不下再分一屏」。

## 调整

| 想做的事 | 怎么做 |
| --- | --- |
| 挪动一屏 | 拖动它顶部中间的小横条；或右键会话，选「向左移动分屏」之类的选项 |
| 改宽度或高度 | 拖动两屏之间的分隔条，双击恢复均分 |
| 关掉一屏 | 点标题栏上的「关闭此屏」，会话本身不受影响 |
| 单独开一个窗口 | 右键会话 →「打开方式」→「新窗口」 |

## 要点

- **面板属于会话**：每一屏的浏览器标签、终端都是各自的；「文件内容」里打开的文件整个窗口共用一份。
- **保证能读**：聊天区至少 420 px 宽，每个面板至少 300 px。窗口缩窄放不下时，两个面板会上下叠起来；再窄，旁边的面板会盖住对话的一部分，放宽后恢复。
- **布局会记住**：重启之后还是原来的样子。

<Aside type="tip">
面板全屏之后，按 `Esc` 退出。它只退出全屏的面板，不会关掉旁边的屏。
</Aside>
