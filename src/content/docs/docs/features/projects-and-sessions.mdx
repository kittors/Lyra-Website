侧栏按项目归拢会话，也能不分项目、按时间看全部聊天。`⌘B` 显示或隐藏侧栏。

## 窗口一览

| 位置 | 内容 |
| --- | --- |
| 顶栏 | 左边是后退、前进和侧栏开关；只开着一个会话时，中间是它的标题和「会话操作」（⋯），右端是终端、浏览器、Git 三个面板按钮和「面板」菜单（⋮） |
| 图标栏（最左一列） | 对话、[拉取请求](/docs/features/pull-requests/)、[已安排](/docs/features/scheduled/)、[插件](/docs/features/plugins/)；底部是设置，有新版本时设置上方多一个更新标记 |
| 侧栏顶部 | 搜索会话、通知（铃铛）、新对话 |
| 「项目」标签 | 按项目分组的会话，置顶的项目排在最上面 |
| 「聊天」标签 | 全部会话，按今天、昨天、过去 7 天等分段 |
| 侧栏底部 | 座右铭，没填时显示配了哪些供应商（「设置 → 个性化 → 侧边栏座右铭」） |

窗口窄于 760 px 时侧栏变成抽屉，图标栏收起，上面这些去处和设置回到抽屉里。后退、前进也可以用 `⌘[`、`⌘]`（Windows 和 Linux 上是 `Alt+←`、`Alt+→`）或鼠标侧键，在输入框里打字时不响应。macOS 上侧栏透出窗口的毛玻璃，不想要可以在「设置 → 外观 → 毛玻璃侧边栏」关掉。

## 项目

项目是一个名字加上一组源文件夹。第一个是**主文件夹**，会话就在里面运行。

- **新建**：点输入框上方的项目按钮 →「新建项目」，起名、添加文件夹。已经有项目之后，侧栏「项目」标题旁也有一个 `+`。
- **项目指令**：在项目里放一份 `LYRA.md`（或 `AGENTS.md`、`CLAUDE.md`），它会作为项目说明带进每个会话。
- **右键项目**：在这里新建会话、置顶、编辑项目、在文件管理器中显示、归档聊天、移除。

移除项目只是把它从列表里拿掉，它的聊天会一起归档，磁盘上的文件不动。

## 会话

- **标题**：先用第一条消息起一个简短标题；消息较长时再请模型总结一个。不想产生这笔用量，可以在「设置 → 常规 → 智能标题总结」关掉。
- **悬停**：行尾有置顶和归档按钮；停一会儿会浮出卡片，显示完整标题、目录和用量。
- **右键**：置顶、重命名、归档、移动到别的项目、复制工作目录或深度链接，以及[分屏或新窗口打开](/docs/features/split-view/)。
- **删除**：先归档，再到归档列表或「设置 → 已归档的聊天」里删除。删除无法恢复；它花过的钱仍然算在「设置 → 使用统计」里。
- **状态**：行上会标出正在执行、等待你的批准、已完成未查看、执行失败未查看。侧栏顶上的铃铛把这些会话（屏幕上正开着的那个除外）和没看过的定时任务失败列在一起，点一行就过去。窗口不在前台时，任务完成会发一条系统通知，点开直达那个会话。

## 排序

侧栏上的「列表设置」里可以选最近更新、最近创建或手动排序。直接拖动项目或会话，就会切到手动排序；拖动途中按 `Esc` 取消。

<Aside type="tip">
想让每个新会话都在独立的 Git 工作树里干活、不碰主工作区？到「设置 → Worktrees」打开「新建会话时自动创建独立工作树」。
</Aside>
