在对话里说「做一段……的视频」「让这张图动起来」，对话模型会调用 `video_generate`：它按上下文写好提示词、指明从哪张图做起，交给你配的视频模型。视频是一个要等的任务，短的半分钟，长的好几分钟，做好以后就在对话里播放。

## 加一个视频模型

<Steps>

1. 「设置 → 模型设置」→ 选供应商 →「添加模型」，填模型 ID，比如 `grok-imagine-video-1.5`、`doubao-seedance-2-5-260628`。
2. 名字里带 `-video`、`veo`、`sora`、`kling`、`seedance`、`hailuo`、`vidu`，或者 `t2v`、`i2v` 这类写法的，模型编辑里的「用途」会自动选成「视频」；别的名字手动选。视频模型不会出现在对话模型的列表里。
3. 「用途」是「视频」时，下面多一个「视频接口」，默认「自动」，见下一节。
4. 点这一行的测试按钮。它会真的生成一段最短的视频，这一次会计费。

</Steps>

## 视频接口

各家视频接口的格式都不一样。「自动」先看供应商的地址，再看模型名：

| 「视频接口」里的选项 | 自动选中它的情况 |
| --- | --- |
| xAI（grok-imagine-video） | 地址是 `x.ai` 的，或者模型名以 `grok-imagine-video` 开头 |
| 火山方舟（Seedance） | 火山方舟的地址，或者模型名里有 `seedance` |
| OpenAI 视频格式（new-api 等中转） | 中转的 `/v1/videos`。可灵、万相、Vidu 这些经中转时，多半走这一种 |
| Google Veo（Gemini API） | Gemini API 的地址，或者模型名以 `veo` 开头 |
| 阿里百炼（万相） | 阿里云的地址 |

地址和名字都看不出来时，依次试 OpenAI 视频格式、xAI、火山方舟，用第一个有这个接口的。在模型编辑里手动选了一种，就只用那一种，不再往下试。

<Aside type="note">
模型编辑里关了「支持图片输入」的视频模型，不能从图片做起。要让图动起来，换一个能收图的模型，或者把这个开关打开。
</Aside>

## 用哪一个

只有一个就用它。有好几个时，在「设置 → 智能体 → 会话 → 视频模型」里选默认的，或者在供应商的模型列表里点「设为默认视频模型」；都没选就用第一个。

某个对话想换一个，用输入框上的魔法棒，或者在消息里 @ 一个视频模型，和[选生图模型](/docs/features/images/#用哪一个)是同一套办法。

## 做的时候

- 视频的位置先按比例占好，是一片缓缓流动的点阵。上方写着做到哪一步和已经等了多久，比如「生成中 · 已等 1m 12s」；四个阶段依次是「提交中」「排队中」「生成中」「正在取回视频」。
- 右下角是百分比。服务商报进度的，用它报的数；不报的，按这类视频平常要做多久估出来。
- 两次查询之间网络抖一下，不算失败：任务还在服务商那边跑，已经计了费。连着半分钟查不到，或者等满 20 分钟还没做完，卡片才报出来。
- 说「10 秒」「竖屏」「1080p」「不要声音」，模型会照着传给视频模型。每个模型支持的时长不同，取它支持的、最接近的那个。
- 从一张图做起：把图贴进输入框，或者指对话里已有的图（最新的一张是 `#1`，再往前是 `#2`），它就是第一帧。有的模型还能指定最后一帧，或者只借图里的人物和风格。
- 一次最多做四段。

## 看视频

做好的视频用 Lyra 自己的播放器放。暂停时画面中间有播放键，底下一条控制栏：播放、时间、进度条、声音、全屏和「更多」；播放时指针不动，控制栏就让开。

- **全屏**铺满 Lyra 窗口，视频接着放，不会从头开始。真正占满整个屏幕的「屏幕全屏」在「更多」里。
- 点一下画面，就能用键盘：空格或 `K` 播放、暂停，`←` `→` 前后跳 5 秒，`M` 静音，`F` 铺满窗口，`Esc` 退回去。
- 悬停时右上角有「换个视频模型重做」和「下载」。前者要配了两个以上视频模型才有，提示词和画面参考都不变。

文件面板里的视频文件，用的也是这个播放器。

## 做失败时

卡片上会写明原因：

| 卡片上写着 | 怎么回事 |
| --- | --- |
| 生成任务找不到了 | 任务过期了，或者中转重启过。再做一次就行 |
| 等太久，视频还没生成完 | 等满了 20 分钟。服务商那边可能还在做，任务没有取消 |
| 已停止等待，服务商那边可能已经计费 | 你停下了这一轮。Lyra 不再等，但已经提交的任务可能照样计费 |
| 额度用完、密钥不能用这个模型、被内容安全策略拒绝 | 和画图一样，见[画失败时](/docs/features/images/#画失败时) |

## 要知道的

- 每段视频都是一次计费的调用，费用由视频模型的供应商收。你没说要几段，模型就只做一段；没被要求，它也不会重做。
- 做好的视频和图存在一起，在 `~/.lyra/session-media/`，重开会话还在。
- 所有对话里做过的视频都收在左侧图标栏的「创作」里，见[创作](/docs/features/studio/)。
