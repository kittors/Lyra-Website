左侧图标栏的「创作」里，是所有对话里[画过的图](/docs/features/images/)和[做过的视频](/docs/features/video/)。不用记得是在哪个对话里画的，到这里找就行。

## 浏览和搜索

- 作品按天排开：今天、昨天，再往前写日期。每张按自己的比例显示，16:9 的图不会被裁成方块。
- 视频角上有播放标记和时长；从别的图改出来、或者被改过的图，角上写着它的生成链路有几步。
- 悬停能看到当时说的那句话。标题右边的搜索框，按说过的话、提示词或对话名找。
- 进「创作」时会话列表自动收起，回到对话再展开。想在这里看会话列表，点侧栏开关，只管这一次。

## 点开一张

图放大在左边，点图还能再放大。右边从上往下是：

- **对话名、时间和项目**。「在对话中查看」打开那个对话，滚到这张图，图框闪一下。旁边是下载。
- **生成链路**，见下一节。
- **提示词**：交给生图或视频模型的那段话，可以复制。服务商改写过的，下面写着它改成了什么。
- **参数**：模型、尺寸、比例、耗时；图还有清晰度，视频还有片长。

`←` `→` 切到上一张、下一张，`Esc` 回到「创作」。视频在这里直接播放。

## 生成链路

一张图往往不是一次画成的：先画一只狗，再给它戴上帽子，再让一个女孩抱着它。生成链路从第一张起，把每一步排成一列：

- 每一步写着你当时说的话，和这一步做了什么：生成、修改、做成视频、生成视频。你附上的图写「你附上的图片」，标注过的写「在图上做了标注」。
- 同一张图往两个方向改过的，另一条分支整段列在后面，用左边的线接回它是从哪张分出来的。眼前这张图自己的来路用强调色标出来。
- 点链路里的任何一张，就切到它。
- 同一张图附到别的对话里接着改，或者在分叉出来的对话里接着改，也连在同一条链路上。

<Aside type="note">
0.9.27 之前画的图没有记下每次改的是哪一张，链路是按当时用的 `#1`、`#2` 倒推出来的。推不出来的那一步，标着「原图找不到了」。
</Aside>

## 不出「创作」再改一次

图下面有一个输入框。写一句要怎么改、回车，就带着这张图发回它所在的对话，Lyra 切到那个对话去画。画好之后再回「创作」，停在新的那张上。

- 先点输入框左端的笔「在图上标注」，圈出要改的地方，按「完成」，标注过的图出现在输入框里；再写一句发出去，标注的那一步也会进链路。只标不写、直接发，那个对话会打开，标注过的图放在它的输入框里，等你说怎么改。
- 那个对话正在忙时，回车照样能发，消息排在这一轮后面。
- 视频没有这个输入框。
