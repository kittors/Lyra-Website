在输入框里说要做什么，Lyra 调用工具去做，每一步都摆在对话里。

## 输入框

| 输入 | 作用 |
| --- | --- |
| `/` | 内置命令、自定义命令、技能 |
| `@` | 引用文件、文件夹、技能、智能体、历史会话 |
| 拖入、粘贴或点 `+` | 添加文件和图片，见[附件、文件预览与面板](/docs/features/files-and-panels/) |
| 模型名和旁边的推理强度 | 切换模型和推理强度，只影响当前会话 |
| 左下角 | 切换权限模式 |

一轮还在跑时也能接着打字：新消息会排队，等这一轮结束再发；点「现在就发」可以立刻送进去，不打断正在跑的这一轮。

## 权限模式

| 模式 | 行为 |
| --- | --- |
| 请求批准 | 写文件、执行命令、访问网络之前都先问 |
| 帮我批准（默认） | 只读的命令自动放行，其余仍然问 |
| 完全访问 | 全部直接执行 |

批准时可以选「允许一次」或「以后不再问」；要在沙箱外运行的命令只能「允许一次」，不会被记住。记住的授权可以在「设置 → 访问授权」里随时收回。没人回应的批准请求，5 分钟后按拒绝处理。

## 内置工具

| 分组 | 工具 |
| --- | --- |
| 文件与代码 | `read` `write` `edit` `ls` `glob` `grep` `symbol` `lsp` |
| 执行命令 | `bash` `bash_output` |
| 会话与记忆 | `todo_write` `task` `skill` `rule` `recall` `learn` `ask_user` |
| 网络、预览与画图 | `web_fetch` `web_search` `preview` `image_generate` |

`image_generate` 只在配了生图模型时才有，见[画图与改图](/docs/features/images/)。

此外还有操作内置浏览器的工具，以及你启用的 [MCP 服务](/docs/features/mcp/)带来的工具。

`web_search` 不配置也能用，走的是免 key 的 DuckDuckGo，但结果有限，中文尤其差。想搜得好，到「设置 → 网页搜索」填一家的 key（Tavily、Brave、Exa 都有免费额度）。

## 回复里有什么

- **Markdown**：表格、代码块照常渲染，`mermaid` 代码块会画成图。
- **文件链接**：本地文件路径显示成文件图标加文件名，点一下在旁边打开。右键可以用「设置 → 常规 → 默认文件打开目标」里选的应用打开（比如 Zed、Cursor、VS Code），或者选别的应用打开、在访达（Windows 上是资源管理器）中显示、复制路径或相对路径。
- **文件改动**：这一轮改了哪些文件一目了然，可以逐个看差异，也可以撤销这一轮直接写入的改动。「已编辑 N 个文件」卡片上的文件行、差异面板里每个文件的标题行，右键是同一个菜单。
- **工具调用**：一轮里的读文件、改文件、跑命令默认收成一行摘要，跑的时候摘要随调用累加；点开后每次调用各占一行，模型中途说的话留在外面。想要一张张卡片的排法，到「设置 → 外观 → 调用链」选「展开」。
- **图片**：配了生图模型，说「画一张……」，图就画在对话里，见[画图与改图](/docs/features/images/)。
- **提问卡片**：模型拿不准时会列出选项问你。完全访问模式下它也不会替你回答。

你发过的消息可以编辑后重新发送，也可以撤回；出错或被打断的一轮可以「继续」接着做。想换个方向又不想丢掉这条线，用下面的「从这里分叉」。

<Aside type="tip">
有问题想问、又不想打扰正在干活的主会话？按 `⌥⌘S` 打开**侧边聊天**。它读得到主会话的内容，但一个字也不会写进去。
</Aside>

## 从这里分叉

鼠标停在自己发过的一条消息上，点下面那排按钮最右边的「从这里分叉」：

- 新开一个会话，装着这条消息之前的全部对话，标题是「原标题（分叉）」。
- 这条消息的文字、图片、附件和会话引用回到新会话的输入框，改完再发。
- 原会话一个字不动。这一轮还在跑时也能分叉；压缩过的长对话，分叉后照样是压缩过的。

<Aside type="caution">
分叉出来的会话和原会话用同一个工作目录，两边都去改文件会互相覆盖。
</Aside>
