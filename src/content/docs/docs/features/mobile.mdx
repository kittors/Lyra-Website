手机端显示的就是你电脑上的 Lyra：同一份会话，在手机上看进行中的任务、批准操作、继续追问。会话、模型和密钥都留在电脑上。

安装手机端见[安装](/docs/start/install/)。

## 配对

<Steps>

1. 电脑上打开「设置 → 移动端同步」，启用同步服务。
2. 手机上打开 Lyra →「开始配对」→「扫码连接」，对准电脑上的二维码。
3. 扫不了的话，把配对链接复制到手机上粘贴；或者手动填地址、端口（默认 4517）和配对令牌。

</Steps>

## 三种连法

| 方式 | 怎么连 | 适合 |
| --- | --- | --- |
| 局域网 | 手机直接连电脑 | 在同一个 Wi-Fi 下，最快 |
| 公网地址 | 经你自己的域名或端口转发 | 已经有域名和反向代理 |
| 中转 | 电脑和手机都主动连到一台中转服务器 | 两边谁也连不上谁 |

后两种要在「移动端同步」里打开「使用公网反代 / 中转服务器」，再填地址。

## 中转服务器

中转需要你自己部署。它是 [Lyra 仓库](https://github.com/kittors/Lyra)里的一个单文件 Node 程序，没有依赖，Node 18.17 以上就能跑。在仓库根目录运行：

```bash
node packages/relay/server.mjs            # 默认端口 8787
PORT=9000 node packages/relay/server.mjs
```

建议放在 nginx 或 Caddy 后面加上 TLS，然后在电脑上填 `wss://你的域名`。

<Aside type="caution">
中转拿不到你的配对令牌，但它能看到经过它的数据，不是端到端加密。只用你信得过的中转，放在公网上一定要加 TLS。
</Aside>

## 手机上能做什么

| 能做 | 不能做 |
| --- | --- |
| 新建、发送、停止、批准、编辑重发、切换模型、压缩上下文 | 终端、内置浏览器、Git |
| 侧边聊天、任务、轨迹、子 Agent | 写入或删除文件 |
| 浏览项目里的文本文件（只读） | 截图 |
| 改外观、默认模型、推理档位、权限模式 | 改模型供应商和密钥、MCP、钩子、定时任务 |
